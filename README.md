# Kirill Kulinkin — game design portfolio

A 3D cartridge club: 89 playable browser games and 20 game teardowns on neon shelves. Pick a cartridge and it plays on the TV.

**Live site:** https://k5302964-sketch.github.io/portfolio/

## What's inside

| Path | What it is |
|---|---|
| `index.html` | The club: the 3D shelves, with all titles, descriptions and covers built in |
| `g00.html` … `g88.html` | Playable builds, each one self-contained HTML |
| `td/t00.html` … `td/t19.html` | Teardown reports |

To preview locally: `python -m http.server` in this folder, then open http://localhost:8000/.

## Credits

Reference games belong to their developers and publishers; they were analysed, not copied. Teardown screenshots are frames from public gameplay videos, used for analysis.
